# __HOW TO BUILD__
Willing to use this code for your needs? Here's a quick guide on how to build this project!
The project consists of a bunch of header files inside `include/` and source files located inside `src/`. Those files constitute the core of the _0-1 Test for Chaos_ implementation. Inside of a `examples/` directory a few `.cpp` files were provided to showcase the test usability and how to write your own code to perform desired actions.
